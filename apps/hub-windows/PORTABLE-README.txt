DJ4GHUB · 老李 Oldlee — Windows 公开源码准备版 0.6.7

启动 DJ4Hub.Windows.exe。请保留整个目录，不能只复制这一个 EXE。
需要 Windows 10/11 x64、WebView2 Runtime 和兼容模块的已签名 USB/AT 驱动。
插入模块后可直接本地使用；无需云账号，也不需要购买服务器。
可同时连接两块模块，点击模块卡片切换控制。各模块独立运行后端与数据目录。
云同步默认关闭，地址留空。需要远程控制时，自建 HTTPS 中继并配置自己的凭据。
详情见仓库 README、docs/QUICK_START.md、docs/SELF_HOSTING.md。
此公开包不包含私人的云服务器地址、密码、推送密钥或设备配置。
