# 隐私与脱敏说明

## 本地模式

云同步关闭时不向中继同步设备快照。用户主动启用通知、下载 eSIM Profile 或其他联网功能时，会与相应第三方服务通信；“本地优先”不等于所有功能完全离线。

配置、短信历史和其他运行数据位于用户应用数据目录。它们可能包含设备身份、号码、短信、Profile 信息和推送凭据。公开源码只含代码和人工演示数据，不包含作者的这些文件。

## 云同步模式

用户主动启用后，主机向所选 HTTPS 中继发送设备快照与执行结果；快照/命令可能涉及 IMEI、ICCID、手机号、短信和卡片信息。中继持久化状态加密，但服务器持有密钥，不是服务端不可读的端到端加密。

同一实例的管理员可操作所有注册设备。不要在不信任的别人服务器上输入 owner token 或同步私人短信。关闭同步不会自动删除服务器上已经保存的数据；删除和备份清理要在自己的实例上管理。

## 通知

Bark / Telegram 由用户自行配置，可能传送短信正文，包括验证码。启用前确认服务方、账号安全和内容风险。第二模块可能首次继承通知配置，接入后分别检查。

## 本次公开包如何脱敏

- 从私有工作目录导出白名单源码，不拷贝原 `.git` 与旧历史。
- 不导出安装数据、私人部署脚本、服务器文件、备份、日志、数据库和旧截图。
- 去除个人云端默认地址；地址留空、同步关闭，使用者自行配置。
- 将发现的真实设备测试身份替换为固定虚构值。
- 配图使用隔离演示环境；头像仅作为作者指定的品牌素材。
- 凭据在运行时由使用者生成/填写，公开 `.env.example` 仅含保留示例域名。

`scripts/audit-public.ps1` 检查私人路径/服务地址/凭据文件与敏感字面量等风险；它不是通用 DLP 或独立安全审计，不能保证将来的每次改动自动无泄露。发布者仍需检查新增二进制、图片、历史与 CI 日志。

## 提交问题前

不要贴完整 IMEI、ICCID、IMSI、EID、号码、短信正文、二维码/激活码、Bark URL、Telegram Token、owner/host/client token、TOTP 或控制台密码。即便诊断导出自称脱敏，也要自行复核。截图仅打码文字不够，二维码同样要删除或遮盖。
